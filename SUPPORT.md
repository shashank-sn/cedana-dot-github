# Get help with Cedana

Pick the route that fits what you need.

## How do I install or use Cedana?

Start with the docs at https://docs.cedana.ai:

- Kubernetes: https://docs.cedana.ai/cedana-kubernetes/installation
- Slurm: https://docs.cedana.ai/cedana-slurm/installation
- The daemon and the `cedana` command: https://docs.cedana.ai/daemon

## Something does not work as the docs say

Open an issue in the repository it belongs to:

- The daemon, the `cedana` command and its plugins: [cedana/cedana issues](https://github.com/cedana/cedana/issues)
- The Helm chart: [cedana/cedana-helm-charts issues](https://github.com/cedana/cedana-helm-charts/issues)
- The sample workloads: [cedana/cedana-samples issues](https://github.com/cedana/cedana-samples/issues)

Include the version (`cedana version`, the chart version or the image tag), your Linux distribution and kernel, the container runtime, the Kubernetes or Slurm version, and the GPU and driver.

## A security problem

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and report it privately on GitHub.

## Talk to Cedana

For a demo or a question about your deployment, go to https://cedana.com/demo/ or write to contact@cedana.ai.
